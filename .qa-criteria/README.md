# Blind product criteria

The user or an independent tester owns `holdout-scenarios.md`. Development,
research, review, and QA-dispatch roles must not read it. The product tester may read
it only while evaluating a running artifact.

Do not populate the holdout file with criteria generated by the implementation agent;
that defeats the point. Keep it local or grant access only to the tester if your
workflow cannot enforce role-specific file access.
