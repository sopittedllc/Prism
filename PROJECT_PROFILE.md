# Generic Project Profile

Use the boundaries and verification matrix in `PROJECT.md`, `TOOLCHAIN.md`, and
`docs/architecture/overview.md`. Replace this file with a domain profile or add the
project's domain-specific constraints here.

Before implementing, explicitly identify:

- execution and concurrency model;
- ownership/lifetime rules;
- external API and version boundaries;
- performance and resource budgets;
- supported targets/configurations;
- recovery behavior and realistic runtime validation.
