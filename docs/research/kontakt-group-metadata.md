# Read-only public Kontakt group metadata research (2026-10-04)

This note contains no patch binaries, sample data, scripts, licenses, account data, or absolute private library paths. It describes observed format metadata and source references for implementation review. Research clones and temporary executables remain outside the Simplify repository.

## Minimal decode path, in original prose

- Outer NIS item is a little-endian `u64` length-delimited block; its contents start with `u32` header version 1, ASCII `hsin`, two `u32` fields, 16-byte UUID, a length-delimited data-chunk chain, then `u32` item version and `u32` child count. Every child has `u32` index, 4-byte domain, `u32` type, and another bounded NIS item. Validate block boundaries/count/depth before descent.
- Data chunks are `u64` length-delimited. Each has 4-byte domain, `u32` type, `u32` version 1, optional nested next data chunk unless type 1 terminator, then type-specific data. Relevant type 101 is authoring application; type 109 is preset chunk; type 115 is nested subtree. Type 106 is authorization; never bypass protected/encrypted content.
- Subtree type 115 data begins `u32` version 1 and `u8` compression flag. If flag zero, another NIS item follows. If nonzero, `u32` uncompressed size, `u32` compressed size and exactly that many compressed bytes follow; ConvertWithMoss uses FastLZ. Apply strict decompression caps and fail closed on invalid or apparently encrypted data. Prism's existing saved-state reader marks this branch opaque, so this is an extension, not a currently supported path.
- Preset type 109 data begins `u32` version 1, `u32` dictionary type, `u32` entry count (reader supports one), `u32` item byte length, `u32` reference, then bounded preset bytes, followed by two `u32` trailer fields. Do not scan arbitrary bytes for plausible names.
- Within preset bytes, each object starts `u16` chunk ID, `u32` object byte length and exactly that many bytes. Program is ID `0x28`; GroupList is `0x33`. Structured objects begin `u8` true, `u16` version, `u32` private byte count + bytes, `u32` public byte count + bytes, and `u32` child-byte count + bounded child chunks. Skip private data, scripts, zones and sample data. GroupList payload starts `u32` group count, then consecutive structured group objects without individual ID/length headers. Each group's public bytes start with `u32` UTF-16 code-unit count and that many UTF-16LE bytes for its name. Validate UTF-16 and length bounds.
- The generic result is a list of group names and explicit format/unsupported status, not a list of articulations. Articulation qualification is a separate versioned vendor profile with evidence and path/hash binding.

## Local contrasting observations

- Installed Spitfire Chamber Strings Celli Core primary: NISound 1.7.14, Kontakt patch 6.1.1.255, 426 groups, 61 unique group names. Exactly 17 numbered technique-brush headers. Fifteen use `from ../technique brushes/` and have three per-mic label groups; two use `from rest shells`. Live Kontakt 8.13.1 UI verified the same 15 playable labels and two unavailable slots. The two unavailable slots are Spiccato Feathered and Staccato Dig. Exact primary NKI: 917613 bytes, SHA-256 a720ade2d31476a94f2de13f35f9539b8d8b670c0579e9585b1ea56693690e7a. The variant `Alt` is a distinct binary (922333 bytes, SHA-256 133ce320c238142c9033b705a44d75e829cca06a52a676a9a3187b56a1cc1a87); same 15/2 UI observation, but do not infer the other variant contents.
- Installed Spitfire Symphonic Strings Celli Core: 430 groups, 70 unique group names, 18 numbered technique-brush headers. Sixteen headers reference `../technique brushes/`, two (`long sul tasto`, `long sul g`) say `from rest shells`. This is a second positive structural example of the same pattern, but playability is metadata-inferred only; it has not been independently checked in player UI. SHA-256 5e50b70e4c1089cbcaeb42b32a6735925d4164b5d63d0bd74f5fd6cfed3163fd.
- Aaron Venture Infinite Brass Horn 3: nine groups named legato/sus in dynamic layers plus noise. Group names are not nine articulations. Generic group→articulation conversion would be false.
- Max Richter Strings Cello 1 Legato, NI Poiesis Cello Articulation Keyswitch, and Vessels Convergent Pulse each caused the current ni-file research parser to fail with UnexpectedEof. The exact failure cause is unproven; parsing only required public GroupList branches in a small Swift reader may avoid its complex full-program/zone handling, but must be tested. No universal coverage claim is justified.

## Recommendation

Implement a small metadata-only, fail-closed Swift reader alongside the existing NIS reader using the licensed ConvertWithMoss format description as a reference, with exact test fixtures sourced from installed metadata and no sample/script extraction. Expose parsed group names only to explicit, versioned articulation profiles. Start with Spitfire numbered technique-brush headers and distinguish brush references from rest-shell placeholders. Exact Core patch hashes are regression ground truth and cache provenance, not a production per-file whitelist; production qualification uses verified vendor identity, tested source structure, and source-stability checks. Existing Apache-2.0 Reaticulate Chamber Strings Core bank 64/15 corroborates the 15 primary labels as a data fallback, not a generic product-wide membership rule. Keep unsupported patches indexed as patches with articulation state unresolved.
