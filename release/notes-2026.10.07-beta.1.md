# Prism 2026.10.07 beta 1

This first public beta helps musicians browse installed plugins, sample libraries, individual sounds, and saved-project references in one local catalog. It is an **Apple Silicon** build with a minimum macOS version of **13**. It has been validated on macOS **26.7**; older supported macOS versions have not yet been tested. Intel Macs are not included in this beta.

Set up Sample Libraries, optional Individual Sounds, and optional DAW Projects, then review the locations before scanning. Standard system plugin folders are included automatically. **Check For Updates** rechecks the whole collection; **Stop** leaves the last saved catalog available. The scan reads your files without editing, uploading, or sharing their contents. Catalog data stays on your Mac.

Prism shows physical size only when it can measure a supported, reachable source safely. A measured SINE content pair or candidate folder is not a complete product size or an estimate of reclaimable disk space. If a location is unavailable or a format is not understood, Prism keeps that uncertainty visible rather than inventing zero size, absence, or usage. **Last Used** requires a qualified saved-project reference; it is not a playback history. **Not Used Yet** means no qualifying saved-project reference was found in the scanned projects, not proof the item has never been used. Saved-project validation across Logic, Ableton Live, Cubase, and Pro Tools remains incomplete for release-quality cleanup decisions.

Prism can move explicitly reviewed plugin installations to macOS Trash. Before using that action, check the full path and format list and keep your own backup. The beta does not remove samples or libraries. There is no automatic updater yet.

To install, open the DMG and drag **Prism.app** to **Applications**. Use the beta invitation or [Prism issues](https://github.com/sopittedllc/Prism/issues) to report a problem, including the app version and build number shown in Finder’s Get Info. Avoid posting project files, sample paths, or local catalog data in a public issue.
